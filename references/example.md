# Self-authored demonstration

`assets/synthetic-example` contains ethanol and benzene CDXML drawings created specifically for this repository, plus an editable text layout. It contains no literature screenshots, private paths, external templates, or runtime logs.

Use `new_project.py --mode example --destination <new-directory>` to make a standalone copy. The generated slide is a rendering demonstration, not a reaction or scientific result. Replace it with reconstructed evidence when processing a real figure.
